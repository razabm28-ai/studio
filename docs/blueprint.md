# **App Name**: PhoneSwap

## Core Features:

- Listing Creation: Allow users to post new phone listings with photos, descriptions, and pricing information.
- Phone Browsing: Enable users to browse available phones with filtering and search options.
- Direct Messaging: Facilitate direct messaging between buyers and sellers.
- Search and Filter: Implement robust search and filtering capabilities by model, price, and condition.
- Listing Recommendation: Recommend to users new listings which they might be interested in.

## Style Guidelines:

- Primary color: Light blue (#ADD8E6) to evoke a sense of trust and modernity.
- Background color: Off-white (#F0F8FF) for a clean and uncluttered look.
- Accent color: A darker blue (#4682B4) for interactive elements and CTAs to draw attention.
- Font: 'Inter', a sans-serif font with a modern, neutral look, for both headlines and body text.
- Use minimalist, outlined icons to represent categories and actions, maintaining a clean aesthetic.
- Employ a grid-based layout for product listings to provide a structured and visually appealing presentation.
- Implement subtle transitions and animations on user interactions for a smooth and engaging experience.
